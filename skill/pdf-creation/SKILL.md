# PDF Creation Skill

## Purpose
Generate readable and professional PDF documents.

## Workflow
1. Understand the requested document and audience.
2. Organize the content into suitable sections.
3. Generate clear titles, headings, and paragraphs.
4. Use consistent margins, spacing, and typography.
5. Use the available PDF-generation tool to create the file.
6. Check that the output file exists and is not empty.
7. Return the generated file location.

## Rules
- Do not invent research findings, citations, or statistics.
- Use readable layouts and avoid overflowing content.
- Use a page template and page breaks where appropriate.
- Respect the requested output format.

## Tool Requirements
These instructions do not create files by themselves.
Use an available tool or library such as reportlab.
