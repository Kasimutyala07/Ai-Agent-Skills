# PowerPoint Creation Skill

## Purpose
Create clear, professional PowerPoint presentations based on the user's request.

## Workflow
1. Understand the topic, audience, purpose, and requested slide count.
2. Plan a logical sequence of slides.
3. Generate concise titles and slide content.
4. Include an introduction, key points, examples, and conclusion when appropriate.
5. Use bullet points instead of long paragraphs.
6. Use consistent formatting, readable fonts, and suitable layouts.
7. Use the available PowerPoint tool to create a real `.pptx` file.
8. Check that the file exists and contains the expected slides.
9. Return the file location to the user.

## Default Presentation Guidelines
- Use a professional and consistent design.
- Include a title slide.
- Keep each slide focused on one main idea.
- Use concise, relevant bullet points.
- Include a conclusion or summary slide when appropriate.
- Do not invent statistics, references, or research results.
- Use the requested slide count when specified.

## Tool Requirements
This skill provides instructions, not file-generation capability by itself.
Use an available tool or Python library such as `python-pptx` to generate the presentation.
